# Quickstart (live check)

1. Build: `pnpm exec tauri build --debug --no-bundle`; copy the exe to a scratch dir; run with a scratch `REFRACT_DATA_DIR` and own `--remote-debugging-port`.
2. Launch: pane collapsed. Click the rail chevron: pane opens at 320 px. Press Ctrl+Shift+B: collapses. Again: expands.
3. Open Git changes and Subagents, drag the width, quit, relaunch with the same data dir: same state returns.
4. Clean git tree: no count anywhere. Changed files: coloured `+A -D` on launcher and tab, badge on the rail.
