# Ask redesign design reference

This folder holds the 2026-11-18 design reference bundle for epic #1990 (Ask card and Session Q&A redesign). The files are reference assets only: they are not wired into the app, and the hex colours in them are mockup values that must be replaced with Refract theme tokens (`--severity-success` for the emerald accents, `--severity-warning` for the amber note accents). Start with `AGENT_IMPLEMENTATION_PROMPT.md`, then `omp-ask-cards-reference.html`.

- Multi-select view: #1986
- Inline option notes via the N key: #1987
- Collapsible read-only "Questions from the agent" Q&A card: #1988
- Wire and payload contract (per-option recommendation, answer notes): #1989
- Selected option visually distinct: #2027
