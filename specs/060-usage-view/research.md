# Research 060: Usage view

1. **Data source: Refract's own `usage.db`, fed from OMP session files.** Decided by Stuart (ADR 0006). OMP's `stats.db` is 554 MB, refreshes only on `omp stats`, has no reasoning level, and is OMP-internal.
2. **SQLite crate: `rusqlite` with `bundled`, default features off.** No `sqlx` (async runtime and macro weight, no benefit for one local file). Features: `bundled` only; no `backup`, `serde_json`, `chrono` or `vtab`. The worker is a plain `std::thread` with its own connection, so rusqlite's blocking API never touches the IPC thread or the tokio pool.
3. **Session line shape (verified 2026-10-30, real files, field names only).** See spec Clarifications. `usage.premiumRequests` exists and is mostly 0 after the first call of a user turn, which is why it is not the credits source.
4. **AI credits = `cost.total` x 100, `github-copilot` only.** Same as `session/ai_credits.rs`. `omp usage --json` reports the plan limit as 2,000,000 with 69,402 used, in the same unit. `models.db` `premiumMultiplier` is not used.
5. **`omp usage --json` shape (verified):** `{generatedAt, reports:[{provider, fetchedAt, limits:[{id, label, scope, window:{id,label,resetsAt}, amount:{used,limit,remaining,usedFraction,unit}, status}], metadata:{accountId, plan, quotaResetDate}}], accountsWithoutUsage, disabledCredentials, capacity}`. Parse defensively: a missing field drops that limit; the whole call failing leaves the Copilot row (from #1238) intact.
6. **Scan cost.** About 4,200 files at the time of the grill, 2,928 of them nested subagent files. A directory walk plus `metadata()` per file is cheap; only files whose `(len, mtime)` differ from `file_offsets` are opened. Backfill runs newest file first so the dashboard fills usefully.
7. **Partial last line.** OMP appends a line at a time but a read can catch a half-written line. The reader stops at the last `\n`, so the stored offset is always at a line start.
8. **Why one writer.** Parsing `message_end` events separately would need the entry id to dedupe against the file, and the RPC event may not carry it. A nudge costs one small file tail read.
9. **Chart primitive.** No chart component exists under `components/ui/`. Add a small SVG primitive (stacked bars, patterned fills, direct labels, sparkline) rather than a dependency; confirm no charting library is already in `package.json` during task S2-01 and reuse it if there is.
10. **Alternatives rejected.** Reading `stats.db` (ADR 0006); storing prompt prose for a better frustration model (privacy, ADR 0006); a model multiplier table (item 4); a Settings field for the jokes toggle (`ipc.ts` at its cap, `prefs` table instead).
